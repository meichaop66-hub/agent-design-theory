# Agent 设计元理论（元原则层）

> 多 Agent 系统设计的元原则层方法论，为各类 Agent 协作框架提供理论基础。

## 📖 项目简介

本仓库是 **Agent 设计元理论（元原则层）**的唯一真源。元原则层是 Agent 设计理论的最抽象层级，定义了多 Agent 系统设计的核心原则、约束和方法论，可被各类具体的方法论仓库（如 pmo-framework 规则骨架）调用和引用。

**唯一真源**：本仓库（Gitee）——所有版本迭代、接棒恢复均以此为准。
**展示镜像**：飞书（Agent设计理论空间）——owner 阅读查看用，单向同步，不反向改。

## 🎯 定位

元原则层是 Agent 设计理论的**最抽象层级**，具有以下特点：

- **通用性**：不绑定具体行业或场景，适用于各类多 Agent 系统设计
- **基础性**：为具体方法论（如 pmo-framework 规则骨架）提供理论基础
- **可调用**：设计为可被其他方法论仓库直接引用或 fork 的独立理论模块

## 🔄 同步机制

- **Gitee 为唯一真源**：所有规则更新、升版在本仓库完成
- 每次升版后，同步更新飞书展示层的元理论副本（删旧导新，单向同步）
- 本仓库为版本快照，不接受直接 PR 修改；欢迎通过 Issues 提交反馈与改进建议
