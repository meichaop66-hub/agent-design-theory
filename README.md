本仓库是 Agent 设计元理论（元原则层）的开源镜像。元原则层是 Agent 设计理论的最抽象层级，定义了多 Agent 系统设计的核心原则、约束和方法论，可被各类具体的方法论仓库调用和引用。

## 🎯 定位

元原则层是 Agent 设计理论的**最抽象层级**，具有以下特点：

- **通用性**：不绑定具体行业或场景，适用于各类多 Agent 系统设计
- **基础性**：为具体方法论（如 PMO 骨架、行业特供手册等）提供理论基础
- **可调用**：设计为可被其他方法论仓库直接引用或 fork 的独立理论模块
